# 🍺 HAUSBIER

Sitio de HAUSBIER, cervecería artesanal de Villa Mercedes.
Este sitio presenta la marca, el proceso de elaboración y tres estilos de cerveza. Además permite enviar una consulta por el formulario de contacto.

- Matijas, Omar

## 📖 Instrucciones de uso

1. Abrir `index.html` en el navegador.
2. Usar el menú para ir a 🏠 Inicio, 🍻 Productos o ✉️ Contacto.
3. En Inicio, recorrer el proceso de elaboración con los botones **Anterior** y **Siguiente**.
4. En Contacto, completar nombre, email, teléfono y mensaje. Si algún dato no es válido, el aviso aparece debajo de ese campo.
